# Lab 16 KQL Query Library

These queries support the Lab 16 Mini SOC Capstone investigation. They are separated from the lab README so the detection and investigation logic can be reused independently.

The files follow the investigation sequence: endpoint privilege change, alert/incident validation, Azure control-plane attribution, process discovery, PowerShell validation, scheduled-task persistence, ingestion troubleshooting, and final alert/incident validation.

Lab-specific resource names are intentionally retained so the queries match the published evidence. Replace those values when reusing the queries in another environment.
